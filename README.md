# Web Animations API Infinite Runner

An infinite runner demo showcasing the Web Animations API capabilities.

## Controls

| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `ArrowUp` | Jump |
| `ArrowRight` | Speed up |
| `ArrowLeft` | Slow down |

## Features

- Character running animation with sprite sheet cycling
- Parallax scrolling street with animated lane markers
- Dynamic shadow scaling during jumps
- Procedurally spawning cars with rotating wheels
- Speed auto-adjustment over time
- All animations powered by the native Web Animations API

## Running

Open `index.html` in a browser.
